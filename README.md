# Julien Roman 独立站源码

这是按 KOL 问卷和提供的 JR1–JR9 图片制作的法英双语静态网站。默认页面为法语，采用黑色、琥珀金配色，以人物故事、教育内容、社群和 WEEX 品牌合作为主线。

## 文件说明

- `index.html`：法语页面，作为默认首页。
- `index-en.html`：英语页面。
- `styles.css`：桌面端和移动端样式、页面动效。
- `app.js`：菜单、章节切换、时间线、视频弹窗、图库和动效控制。
- `assets/`：本地图片、JR 签名、WEEX 标识、字体及素材清单。

这是可直接部署的源码，不需要安装 npm 依赖或运行前端打包程序。两个语言版本使用独立 HTML 页面，导航结构和外部链接保持一致。

## 本地预览

在本文件所在目录打开终端，执行：

```bash
python3 -m http.server 4173
```

浏览器访问 `http://127.0.0.1:4173/`。英语页地址为 `http://127.0.0.1:4173/index-en.html`。

建议通过本地 HTTP 服务预览。YouTube 嵌入播放器依赖网络，直接双击 HTML 文件并不能代表实际部署后的播放效果。

## 运维部署

将本目录内的全部文件和 `assets` 文件夹一起上传到静态托管目录，保留层级。计划地址为 `https://pro.weex.com/julienroman/`；该地址是否正式开放由运维配置决定。

服务器将 `index.html` 设为默认文件即可。页面使用相对资源路径，可以部署在站点子目录。请提供正常的 HTTPS 访问，保证图片、字体、CSS 和 JavaScript 不返回 404。

如部署到 GitHub Pages：把目录内文件放在发布分支根目录，确认 `index.html` 与 `assets/` 在同一层，再从仓库的 Settings → Pages 设置发布来源。

更新时同步上传两个 HTML 文件、CSS、JavaScript 和有变更的素材。若使用 CDN，请刷新相应资源缓存；需要时一并更新 HTML 中 CSS/JS 的版本参数。

## 已包含的功能

- 法语/英语页面切换及手机导航。
- 三章节人物故事、横向时间线与图片展示。
- YouTube 视频弹窗，提供跳转官方 YouTube 的备用入口。
- Newsletter、YouTube、Telegram 和 Instagram 官方入口。
- FAQ 展开、图库预览、滚动显现和动效减弱选项。
- WEEX 品牌合作展示；导航栏 `WEEX x Julien Roman`、首屏主按钮和移动菜单注册入口均跳转至 `https://www.weex.com/register`，法英两版保持一致。

## 外部服务与账户说明

网站提供跳转 WEEX 官方注册页的入口；实际注册、登录和账户处理均在 WEEX 官网完成。本站不包含自己的账户系统或数据库后台，也不会模拟开户成功。Newsletter 按钮跳转至 `https://www.loeilcrypto.com`，订阅由该官方页面处理。

导航栏、首屏和移动菜单的 WEEX 注册入口统一使用 `https://www.weex.com/register`，未配置邀请码、奖励或产品承诺。YouTube 播放、社媒访问和外部订阅需要用户能够访问相应平台；若嵌入视频加载受限，可以使用“在 YouTube 打开”入口。法英切换翻译本站页面，不能改变外部频道或视频自身的语言。

## 素材与内容来源

- 人物故事、法语原始引语、社媒入口和合作信息来自 KOL 填写的建站问卷。页面其余第一人称叙述为基于资料整理的编辑文案。
- 人物与内容图片来自用户提供的 JR1–JR9 文件，已制作网页用 WebP 版本。JR 签名提取自提供的图片。部分图片做了构图裁切，原始资料未被覆盖。
- 章节中的人物照片用于配合叙事，并不声明照片拍摄于章节所写年份。
- 471K YouTube 订阅、约 1M 月浏览量、2,000+ 视频和 31K+ Newsletter 订阅为本次项目问卷提供的数据快照，不是实时更新的计数器。页内已注明来源时间。
- Kolsquare 入口链接至其官方文章。该文章虽然于 2026 年发布，正文的排行年份为 2025，因此页面使用“2025 年榜单”表述，不将其描述为认证或奖项。
- 视频通过 Julien 的官方频道条目选取，标题在页面中作了适合卡片的缩写或英文转译；视频封面优先加载 YouTube 缩略图，网络受限时回退到提供的编辑配图。播放仍需连接 YouTube。

## 后续维护

可直接编辑两份 HTML 的文字、链接和图片路径，或调整 `styles.css` 的配色与排版。替换视频时同步修改相关按钮的 `data-video`（YouTube 视频 ID）和 `data-title`。

替换 WEEX 注册地址时，请同步检查两份 HTML 的桌面导航、首屏主按钮和移动菜单入口，确保法英版本的跳转一致。

本版用于向 KOL 展示网站原型。正式发布前建议 Julien 校对第一人称叙事、标题、合作表述及数据快照；这不影响本地预览和静态部署测试。
